This source package is an early Android MVP. Account registration, cloud sync, advanced timeline editing, admin authentication, production hosting and Meta publishing are not enabled yet. Facebook publishing must use Meta's official authorization flow; the app will never ask users to type their Facebook password into MovieShorts Pro.
